# p002 多场景基准扩展（一句话、10K、100K 场景）

- 来源：`docs/plan.md` §3、§10（规划移交）
- 内容：
    - 场景定义：在现有的 200K 长上下文基准之外，扩展一句话（短输入场景）以及 10K、100K 场景的任务 Prompt 与评测流程。

- 暂搁：MVP 仅支持 200K 场景，一句话/10K/100K 场景暂不开展
