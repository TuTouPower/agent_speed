# Task spec

## 背景

公开基准契约（`docs/specs/public_site_spec.md`）要求语料为 `django/django` 的有序切片，公开可重建。当前 `fixtures/` 为占位，旧私有语料已删除。本 task 建立公开语料管线和公开任务文本。

## 契约区

### 范围

- pin `django/django` tag `6.1.1`（commit `249b13d6e93ee3164dee8ed1775395622a50c337`），获取其源码与文档。
- 只收源码和文档：排除测试、迁移、locale、生成文件。
- 构建 10K/100K/200K 三档 cl100k 切片与文件清单（manifest），路径有序、最后一文件可被截断。
- 公开任务文本（中文，200K 场景使用）。
- 切片正文、清单、任务文本入库；更新 `.gitignore`。

### 非范围

- 不做调度、采集、报告（t002/t003）。
- 不做一句话/10K/100K 的任务正文与页面形态。
- 不改 `public_site_spec.md`。

### 验收标准

只写可观察、可独立验证的行为；每条使用稳定且不复用的 `AC-NNN`。需真实部署或人工环境验证时在编号前加 `[deploy]`。技术选型不作为行为 AC。

- [ ] AC-001：构建脚本按 pin 的 tag/commit 获取 `django/django`；纳入的文件只含源码与文档，清单中无 `tests/`、`migrations/`、`locale/`、生成文件路径。
- [ ] AC-002：产出 10K/100K/200K 三档切片与 manifest；各档 cl100k token 计数与档位一致（10K/100K/200K），最后一文件允许截断。
- [ ] AC-003：10K 切片是 100K 切片的字节前缀，100K 切片是 200K 切片的字节前缀。
- [ ] AC-004：切片正文、manifest、任务文本在 git 追踪下；仓库内无内部私有语料或旧跑分。
- [ ] AC-005：任务文本为单一公开文件：中文、自然长度，要求分层/模块职责/数据流/技术选型，禁止工具与读写文件。

### 有意不测

- 一句话场景：MVP 不跑，无对应任务正文。
- 10K/100K 页面形态：MVP 不上站。

### 测试策略

- pytest：清单路径排除规则；切片 token 计数；字节前缀嵌套；任务文本存在与要求检查。
- 构建脚本从本地克隆重建，重跑产物一致。

未核实的外部契约标为 `UNVERIFIED-BLOCKING` 或 `UNVERIFIED-SPIKE`；核实后改写为结论和验证方式。无则写“无”。

- `django/django` 6.1.1 目录构成与排除规则：已通过浅克隆实际 tag 文件树核实。源码位于 `django/`，文档位于 `docs/`；排除 `tests/`、`js_tests/`、`scripts/`、`extras/`、所有 `migrations/`、所有 `locale/`、构建配置与二进制文件。规则直接由构建脚本和单元测试固化断言。

### 风险与回退

- 风险：文件筛选规则排除文档或不排除生成物；切片 token 计数与档位有偏差。
- 回退：重跑构建脚本重建切片；规则错误由测试失败暴露，修规则重建。

- 无前置 task；需要网络、`git`、`tiktoken`。
- 200K 切片正文入库（约 1.5MB），内容为 BSD 许可的公开代码。
